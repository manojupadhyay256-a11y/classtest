Question: Match the query types with their correct descriptions.
Type: match
Answer:
Select Query : Displays selected data from one or more tables
Parameter Query : Asks for user input via a dialog box before running
Action Query : Modifies, deletes, or adds records between tables
Totals/Summary Query : Calculates sums and averages without showing individual records
Crosstab Query : Displays values with one field on top and another down the side

Question: Match the database objects with their primary functions.
Type: match
Answer:
Table : Stores raw data in rows and columns
Query : Answers specific questions about stored data
Form : Provides an easy-to-understand layout to enter or view one record at a time
Report : Analyzes and formats data for printing or summaries
Navigation Pane : Displays all objects created in the database

Question: Match the dialog options or steps to their actions.
Type: match
Answer:
Show Table : Box used to select tables for setting relationships or queries
Run Button : Executes the designed query
Edit Relationships : Dialog box used to drag and drop matching key fields
Save Object As : Option under File tab to save an individual query or form
Design View : Used to define fields, data types, and primary keys

Question: Match the key concepts to their definitions.
Type: match
Answer:
Primary Key : Field that uniquely identifies each record in a table
Foreign Key : Field storing values matching a Primary Key in another table
Datasheet View : Displays table data in grid format
Query Design Pane : Bottom-half of the query window where criteria are specified
.accdb : Default file extension for MS Access 2010

Question: Match the form navigation buttons to their respective actions.
Type: match
Answer:
First Record : Navigates directly to the very first record
Previous Record : Moves back one record from the current record
Next Record : Moves forward one record after the current record
Last Record : Navigates directly to the final record in the table
New (blank) Record : Opens a blank entry form to insert a new record
